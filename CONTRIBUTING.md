# Contributing

This repository is primarily a personal site for **theworker02**. Production is **deployed on Netlify**. The project is also **available for acquisition, for sale, and customizable** — see [ACQUISITION.md](./ACQUISITION.md).

If you are collaborating:

1. Open an issue or contact via `/contact` with intent **Collaboration** (use **Acquisition** for purchase / customization discussions).
2. Keep PRs focused; do not add auth/login systems.
3. Run `npm run test` and `npm run build` before requesting review.
4. Do not commit secrets, contact logs, or `.env.local`.
5. Follow [CONTENT_GUIDE.md](./CONTENT_GUIDE.md) — no fabricated metrics.
6. Prefer changes that remain deployable on **Netlify** (`netlify.toml`).
